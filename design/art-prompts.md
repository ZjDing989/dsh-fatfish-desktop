# 大肥鱼美术记录

当前插件使用 AI 生成的透明 PNG 状态贴图，存放于 `plugin/native/assets/`。以下记录角色要素和编辑要求的摘要，供维护时参考；不是生成工具逐字提示词日志。

## 参考来源

- 用户指定的[贴吧大肥鱼形象参考](https://tieba.baidu.com/p/10941228631)。
- 原始参考图仅用于本地设计参考，不纳入公开仓库或安装包；本项目生成素材的许可与出处见 [ASSETS.md](../ASSETS.md)。
- 形象要素：蓝色渐变长发、蓝色大眼睛、蓝白鲸鳍、宽大蓝鲸尾、白色蕾丝女仆头饰、蓝白女仆裙与鲸鱼装饰，整体为精细的 Q 版角色。

## 生成与状态编辑要求摘要

基础角色：完整全身、可爱 Q 版比例、清晰轮廓、蓝白海洋配色、透明背景，无文字、无界面边框，适合作为 Windows 桌面宠物贴图。

在同一角色基础上生成四个状态，保持脸型、发型、服装、鲸尾与整体比例一致，脚底基线和画布对齐，以便切换时稳定显示：

| 状态 | 主要编辑要求 | 运行文件 |
|---|---|---|
| 待机 | 睁眼微笑，双手自然放在身旁 | `fatfish-idle.png` |
| 悬停 | 微笑，一只手抬起打招呼 | `fatfish-hover.png` |
| 拖动 | 睁大眼睛，圆形惊讶嘴，双手向两侧张开 | `fatfish-drag.png` |
| 眨眼 | 保留待机姿势，双眼闭合并微笑 | `fatfish-blink.png` |

`fatfish.png` 与 `fatfish-idle.png` 相同，供默认加载使用。待机呼吸、悬停互动、拖动摆动和松手回弹由 WPF 辅助进程实现，贴图无需包含动画编码。

早期草稿与预览工具不作为当前插件的构建来源，不纳入公开仓库或安装包。
